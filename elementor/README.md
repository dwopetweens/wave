# NDC Consulting Group: homepage (Elementor + Hello)

`ndc-homepage.json` is an Elementor page template for the homepage in the design screenshots. It has these sections:

1. **Header**: NDC wordmark, About / Services / Process links, and a Contact Us pill.
2. **Why NDC?**: the copy from *Why NDC Consulting Group – Homepage.docx*, with the key phrase highlighted in sky blue.
3. **About us**: "We make the business work better." with a "Let’s talk about your business →" link.
4. **What we do**: Human Resources, Internal Communications, Customer Retention & Recovery, Marketing Operations.
5. **Our process**: Discover → Design → Implement, on a dotted timeline.
6. **Start the conversation**: a call to action, plus the footer strip.

It uses only **free Elementor** widgets (Container, Heading, Text Editor, Button, Divider, Icon). Every piece can be edited in the visual editor, and you don't need Elementor Pro or any custom CSS.

It was tested on WordPress 6.9.4, Hello Elementor 3.4.7 and Elementor 4.0.0. It should also work on Elementor 3.16+ with the Flexbox Container feature turned on.

## Install

1. **Theme:** activate **Hello Elementor** (*Appearance → Themes*).
2. **Plugin:** install and activate **Elementor**.
   On Elementor 3.x, check that *Elementor → Settings → Features → Flexbox Container* is **Active**. It is on by default in new installs.
3. **Import the template:** *Templates → Saved Templates → Import Templates* → choose `ndc-homepage.json` → **Import Now**.
4. **Create the page:** *Pages → Add New* → title it "Home" → **Edit with Elementor**.
   - Click the folder icon (**Add Template**) → **My Templates** → **Insert** next to *NDC Consulting Group – Homepage*.
   - If Elementor asks whether to apply the template's page settings, choose **Apply**. If it doesn't ask, open the page settings (gear icon) and set **Page Layout → Elementor Canvas**.
   - Click **Publish**.
5. **Make it the homepage:** *Settings → Reading → Your homepage displays → A static page → Homepage: Home*.

**Why Elementor Canvas:** Canvas hides Hello's default header and footer, because the template includes its own. If you'd rather keep Hello's header, choose *Elementor Full Width* and delete the template's header container.

## Things to update after import

| Where | What |
| --- | --- |
| *Start the conversation* → **Contact Us** button | The link is set to `mailto:hello@example.com`. Change it to your real email or contact page. |
| Header → **Contact Us** | Scrolls to the call-to-action section (`#contact`). Change it if you have a contact page. |
| Footer | The copyright year is plain text (`© 2026`). |

## Design tokens

| Token | Value | Used for |
| --- | --- | --- |
| Ink | `#1A1A1A` | Dark sections, text on light sections |
| Cream | `#F6F4E6` | Text on dark sections |
| Sky | `#6EC6EE` | Accent line, highlighted phrase |
| Eyebrow blue | `#2A87B4` | Small uppercase labels |
| About background | `#F4F3EF` | |
| Services background | `#F8F6EB` | |
| Process background | `#DFF0FA` | |

**Fonts (loaded automatically from Google Fonts by Elementor):**
- **Inter Tight** 600 for headlines.
- **Manrope** 500 for the large lead paragraphs.
- **DM Sans** for body text, labels and buttons.

Headline sizes use `clamp()`, so they scale smoothly between phone and wide desktop. Two-column rows stack on tablet or mobile.

**Global colours and fonts (optional):** you can add these to *Site Settings → Global Colors / Global Fonts* so new pages match. The template doesn't depend on them.

## Regenerating the template

The JSON is generated by `tools/build_ndc_homepage.py`, where the colours, fonts, copy and spacing are defined. To regenerate it after editing:

```bash
python3 tools/build_ndc_homepage.py
```

Once the template is imported, you can edit the page directly in Elementor. The script is only for bulk changes.
